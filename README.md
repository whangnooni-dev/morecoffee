# 한 잔 덜, 무엇을 더? ☕

> 작은 소비를 바꾸면, 다른 즐거움이 생겨요.

커피·배달·구독 소비를 조금 줄였을 때 생기는 **연간 절약액**을 계산하고, 그 금액을 🍗 치킨 · ☕ 커피 · ✈️ 여행으로 바꿔 보여 주는 단일 페이지 시뮬레이터입니다.
숫자를 타이핑할 필요 없이 **탭과 슬라이더만으로 10초 안에** 결과를 확인할 수 있습니다.

- 서버, 외부 API, 로그인, 추적 스크립트 없음
- 빌드 도구, 패키지 설치 없음: `index.html` 파일 1개(HTML + CSS + 순수 JavaScript)
- 설정은 이 브라우저의 `localStorage`에만 저장되며 어디로도 전송되지 않음

## 주요 기능

| 기능 | 설명 |
|---|---|
| 카테고리 3종 | ☕ 커피(주 단위), 🛵 배달(월 단위), 📺 구독(월 단위). 탭별 값은 따로 유지돼요 |
| 슬라이더 입력 | 조작 즉시 결과 갱신, 별도 계산 버튼 없음. 정밀 조절용 −/+ 버튼(44px)도 제공 |
| 핵심 결과 | "이렇게 조절하면 1년에 520,000원을 아낄 수 있어요" + 절약률, 한 달 평균 |
| 비교 그래프 | 현재/조절 후 연간 지출을 가로 막대 2개로 비교. 금액과 비율을 글자로 함께 표시 |
| 환산 카드 | 치킨·커피·여행으로 각각 따로 환산. 기준 가격 프리셋을 카드에서 바로 변경 |
| 따뜻한 한마디 | 카테고리와 절약 여부에 맞는 고정 문구. 비난·죄책감 유발 표현 없음 |
| 계산 근거 | 지금 입력값을 그대로 넣은 계산식을 항상 확인 가능 |
| 자동 저장/복원 | 300ms 디바운스 + 조작 완료·페이지 이탈 시 즉시 저장. 새로고침 후 이어서 사용 |
| 전체 초기화 | 확인 대화상자 후 앱 전용 저장 키만 삭제(`localStorage.clear()` 미사용) |

### 사용성 향상 포인트

- **입력 옆 맥락 힌트**: "주 5회 → 주 3회로 조절해요", "1주일에 25,000원을 쓰고 있어요"처럼 숫자의 의미를 바로 풀어 줘요.
- **모바일 결과 미리보기 바**: 휴대폰에서 슬라이더를 움직이는 동안 결과 카드가 화면 아래에 있으면, 하단 바에 절약액이 실시간으로 보이고 누르면 결과로 이동해요.
- **데스크톱 2열 + 고정 입력 영역**: 768px 이상에서는 입력/결과가 나란히 놓이고, 입력 카드는 스크롤해도 따라와요.
- **자동 연동 제한**: 현재 횟수를 줄이면 줄일 횟수도 자동으로 새 최대값까지 낮아지고, 0회면 슬라이더가 잠기며 이유를 알려 줘요.
- **접근성**: 키보드(탭 ←/→/Home/End, 슬라이더 방향키), 포커스 테두리 유지, `aria-valuetext`로 단위 포함 값 낭독, 조작이 멈춘 뒤 한 번만 결과 안내(`aria-live="polite"`), `prefers-reduced-motion` 지원.
- **안전한 복원**: 손상되거나 범위를 벗어난 저장값은 필드 단위로 복구하고, 저장이 막힌 환경에서도 계산은 그대로 동작해요.

## 계산 규칙

| 구분 | 현재 연간 지출 | 연간 절약액 |
|---|---|---|
| 커피 | 가격 × 주간 횟수 × 52 | 가격 × 주간 줄일 횟수 × 52 |
| 배달 | 주문 금액 × 월간 횟수 × 12 | 주문 금액 × 월간 줄일 횟수 × 12 |
| 구독 | 월 구독료 × 12 | 월 구독료 × 이용하지 않을 개월 수 |

- 조절 후 연간 지출 = 현재 지출 − 절약액, 절약률 = 절약액 ÷ 현재 지출 × 100 (반올림, 현재 지출 0이면 0%)
- 환산 값 = 연간 절약액 ÷ 기준 가격 (치킨 2만/2.5만/3만원, 커피 3천/5천/7천원, 여행 30만/50만/100만원)
- 결과는 입력 조건에 따른 **예상치**이며 실제로 모은 금액이 아닙니다. 물가 상승·이자·실제 달력은 반영하지 않습니다.

기본값 예시(커피 5,000원 × 주 5회, 주 2회 줄이기): 현재 연 1,300,000원 → 절약 **520,000원**(40%) → 조절 후 780,000원 · 치킨 약 20.8마리 · 커피 약 104잔 · 여행 약 1회분

## 로컬에서 실행

```bash
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 을 열면 됩니다. `index.html`을 파일로 바로 열어도 동작하지만, 저장·복원 확인은 `localhost` 또는 배포 URL에서 하세요.

## Vercel 배포

빌드 과정이 없는 정적 사이트라 설정 없이 배포됩니다.

**대시보드에서**

1. [vercel.com/new](https://vercel.com/new)에서 이 GitHub 저장소를 Import
2. Framework Preset: **Other**, Build Command / Output Directory는 비워 둠(루트의 `index.html`이 그대로 서빙됨)
3. Deploy

**CLI에서**

```bash
npx vercel --prod
```

`vercel.json`에는 보안 헤더(`nosniff`, `no-referrer`, 프레임 차단 등)만 들어 있고, `.vercelignore`로 문서·테스트 파일은 배포에서 제외됩니다. 콘텐츠 보안 정책(CSP)은 `index.html`의 `<meta>` 태그에 들어 있어 어떤 호스팅에서도 외부 리소스 요청을 막습니다.

> 저장은 같은 origin(도메인)에 한정됩니다. 프리뷰 URL과 프로덕션 URL은 서로 다른 저장 공간을 사용해요.

## 인수 기준 점검 (선택)

PRD의 AC-01 ~ AC-13을 자동으로 점검하는 스크립트가 `tests/acceptance.cjs`에 있습니다. 앱 자체에는 의존성이 없고, 이 스크립트만 [Playwright](https://playwright.dev)를 사용합니다.

```bash
npm i -D playwright && npx playwright install chromium
```

```bash
python3 -m http.server 8765 &
BASE_URL=http://localhost:8765/ node tests/acceptance.cjs
```

기본값 계산, 탭별 값 유지·복원(조작 직후 새로고침 포함), 손상 데이터 복구, 저장 차단, 초기화 확인/취소와 다른 저장 키 보존, 360px 가로 스크롤·44px 터치 영역, 모션 감소, 외부 요청·콘솔 오류 여부를 확인합니다.

## 파일 구성

```
index.html            앱 전체 (HTML + CSS + JS, 외부 의존성 없음)
vercel.json           Vercel 보안 헤더 설정
.vercelignore         배포 제외 목록
docs/PRD.md           제품 요구사항 문서
tests/acceptance.cjs  인수 기준 자동 점검 (Playwright)
```

`index.html` 내부 스크립트는 기본 설정/상태 → 검증(`normalizeState`) → 순수 계산(`calculateAnnual`, `calculateConversions`) → 렌더링(`render`) → 저장(`loadState`, `saveState`, `resetState`) → 이벤트 연결 순서로 구성되어 있습니다. 계산 함수는 DOM과 `localStorage`에 접근하지 않으며, 화면 갱신은 `textContent`만 사용합니다.
