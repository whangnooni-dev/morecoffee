# PRD | 한 잔 덜, 무엇을 더? ☕

- 버전: 1.0 · 작성일: 2026-11-03
- 문서 상태: MVP 개발 착수 기준
- 제품 형태: 서버·외부 API 없이 실행하는 단일 페이지 소비 절약 시뮬레이터

## 1. 제품 목적

커피·배달·구독 소비를 조금 줄였을 때 생기는 연간 절약액을 계산하고, 치킨·여행 등 친숙한 대상으로 환산한다. 사용자는 숫자를 타이핑하지 않고 탭과 슬라이더만 조작하며 10초 안에 첫 결과를 확인한다.

소비를 비난하거나 절약을 강요하지 않는다. “작은 조절로 다른 즐거움을 더한다”는 긍정적인 경험을 제공한다.

## 2. 대상 사용자와 핵심 시나리오

- 대상: 일상 소비의 누적 금액이 궁금한 일반 사용자.
- 사용 장면: “커피를 주 2잔만 줄이면 1년에 무엇을 할 수 있을까?”를 가볍게 확인한다.
- 흐름: 접속 → 기본 커피 결과 확인 → 가격·횟수 조절 → 줄일 횟수 조절 → 절약액·환산 카드 확인 → 새로고침 후 이어서 사용.
- 성공 기준: 첫 화면에 기본 결과가 보이고, 모든 조절이 즉시 반영되며, 새로고침 후 마지막 선택과 입력값이 복원된다.

## 3. MVP 범위

| 포함 | 제외 |
|---|---|
| 커피·배달·구독 개별 계산 | 세 항목 합산 가계부 |
| 슬라이더 기반 입력과 실시간 결과 | 금융계좌·결제내역 연동 |
| 연간 절약액, 현재/조절 후 지출 비교 | 실제 절약 실적·지출 기록 |
| 치킨·커피·여행 환산 카드 | 실시간 가격 조회·AI 문구 생성 |
| localStorage 자동 저장과 전체 초기화 | 로그인·서버·DB·기기 간 동기화 |
| 모바일 대응과 키보드 조작 | 이미지 다운로드·SNS 공유 기능 |

결과는 입력 조건에 따른 예상치다. 실제로 저축한 금액으로 표현하지 않는다.

## 4. 화면 구조

한 페이지 안에서 아래 순서로 구성한다. 탭을 바꿔도 페이지 이동은 없다.

1. **헤더:** 서비스명, “작은 소비를 바꾸면, 다른 즐거움이 생겨요” 소개.
2. **카테고리 탭:** ☕ 커피 / 🛵 배달 / 📺 구독.
3. **입력 카드:** 현재 소비와 줄일 양을 조절하는 슬라이더, 단위가 붙은 현재 값.
4. **핵심 결과:** “이렇게 조절하면 1년에 520,000원을 아낄 수 있어요”.
5. **비교 그래프:** 현재 연간 지출과 조절 후 연간 지출을 가로 막대 2개로 비교.
6. **환산 카드:** 치킨·커피·여행으로 각각 얼마나 되는지 표시.
7. **따뜻한 한마디:** 선택한 카테고리와 절약 여부에 맞는 문구.
8. **계산 기준 및 설정:** 계산식, 환산 가격 프리셋, 저장 상태, 전체 초기화.

모바일은 세로 한 열, 데스크톱은 입력/결과 두 열로 배치한다. 첫 화면에서 카테고리와 핵심 결과를 쉽게 찾을 수 있게 한다.

## 5. 입력 명세

모든 금액은 원, 모든 횟수와 개월 수는 정수다. 범위와 간격은 아래 값으로 고정한다.

| 카테고리 | 필드 | 기본값 | 최소~최대 | 간격 |
|---|---|---:|---|---:|
| 커피 | 한 잔 가격 | 5,000 | 1,000~10,000원 | 500원 |
| 커피 | 현재 주간 구매 횟수 | 5 | 0~21회 | 1회 |
| 커피 | 주간 줄일 횟수 | 2 | 0~현재 구매 횟수 | 1회 |
| 배달 | 1회 총 주문 금액 | 25,000 | 5,000~100,000원 | 1,000원 |
| 배달 | 현재 월간 주문 횟수 | 8 | 0~60회 | 1회 |
| 배달 | 월간 줄일 횟수 | 2 | 0~현재 주문 횟수 | 1회 |
| 구독 | 월 구독료 | 15,000 | 1,000~100,000원 | 1,000원 |
| 구독 | 향후 12개월 중 이용하지 않을 개월 수 | 3 | 0~12개월 | 1개월 |

- 배달 주문 금액은 배달비를 포함한 총액이다. 대체 식사 비용을 차감하지 않은 주문 지출 감소액임을 표시한다.
- 구독은 매월 같은 금액을 결제하는 서비스 1개를 가정한다. 실제 해지 실행, 위약금, 연간 결제 할인, 환불은 계산하지 않는다.
- 현재 횟수를 줄여 ‘줄일 횟수’보다 작아지면 줄일 횟수도 새 최대값까지 자동으로 낮춘다.
- 현재 횟수가 0이면 줄일 횟수는 0으로 고정하고 해당 슬라이더를 비활성화한다.
- 탭별 값은 별도로 유지한다. 탭 전환으로 다른 카테고리 값을 초기화하지 않는다.

## 6. 계산 규칙

| 구분 | 현재 연간 지출 | 연간 절약액 | 조절 후 연간 지출 |
|---|---|---|---|
| 커피 | 가격 × 현재 주간 횟수 × 52 | 가격 × 주간 줄일 횟수 × 52 | 현재 지출 − 절약액 |
| 배달 | 주문 금액 × 현재 월간 횟수 × 12 | 주문 금액 × 월간 줄일 횟수 × 12 | 현재 지출 − 절약액 |
| 구독 | 월 구독료 × 12 | 월 구독료 × 이용하지 않을 개월 수 | 현재 지출 − 절약액 |

- 커피는 1년을 52주, 배달·구독은 12개월로 계산한다. 실제 달력 날짜와 복리·물가 상승은 반영하지 않는다.
- 금액 계산은 정수로 수행하고 표시할 때 천 단위 쉼표와 ‘원’을 붙인다.
- 절약률 = 절약액 ÷ 현재 연간 지출 × 100. 소수 첫째 자리에서 반올림해 정수 %로 표시한다. 현재 지출이 0이면 0%다.
- 두 막대는 현재 지출을 동일한 100% 기준으로 사용한다. 현재 지출이 0이면 모두 빈 막대로 표시하며 NaN/Infinity를 출력하지 않는다.

### 환산 기준

환산 카드 3개는 같은 절약액을 각 기준으로 독립적으로 비교한다. 동시에 구매 가능한 묶음으로 해석되지 않도록 “각 항목으로 따로 환산한 예시예요”를 표시한다.

| 대상 | 기본 기준 | 변경 버튼 |
|---|---:|---|
| 🍗 치킨 | 25,000원/마리 | 20,000 / 25,000 / 30,000원 |
| ☕ 커피 | 5,000원/잔 | 3,000 / 5,000 / 7,000원 |
| ✈️ 여행 | 500,000원/회 | 300,000 / 500,000 / 1,000,000원 |

- 기준 가격은 예시이며 시장 평균 가격으로 표현하지 않는다. 선택값은 저장한다.
- 환산 값 = 연간 절약액 ÷ 선택한 기준 가격. 중간 계산은 반올림하지 않는다.
- 치킨·커피는 소수 첫째 자리까지 표시하되 끝자리 .0은 생략하고 ‘약’을 붙인다.
- 여행 값이 1 이상이면 같은 방식으로 ‘약 N회분’을 표시한다. 1 미만이면 ‘여행 1회 예산의 N%’로 표시하며 소수 첫째 자리까지 사용한다.
- 절약액이 0이면 모든 환산 결과를 0으로 표시한다. 계산 근거는 항상 확인할 수 있다.

## 7. 문구 규칙

문구는 내장된 고정 텍스트를 사용한다. 재렌더링마다 무작위로 바꾸지 않는다.

| 조건 | 문구 |
|---|---|
| 커피, 절약액 > 0 | “매일의 즐거움은 남겨두고, 가끔의 여행을 더해봐요 ☕” |
| 배달, 절약액 > 0 | “배달 쉬는 날이 모이면, 다음 즐거움의 예산이 돼요 🍳” |
| 구독, 절약액 > 0 | “잠깐 쉬어가는 구독, 다른 즐거움으로 이어져요 🌱” |
| 공통, 절약액 = 0 | “지금의 즐거움을 선택해도 괜찮아요. 궁금할 때 조금씩 바꿔보세요 😊” |

‘낭비’, ‘중독’, ‘실패’, ‘이 돈이면 벌써’ 같은 비난·죄책감 유발 표현은 사용하지 않는다.

## 8. 상호작용 및 상태

- 최초 접속: 커피 탭과 기본값을 즉시 표시한다. 별도 계산 버튼은 두지 않는다.
- 슬라이더의 input 이벤트마다 상태 변경 → 계산 → 텍스트·그래프 갱신을 수행한다.
- 저장은 300ms 디바운스하며 change 이벤트와 pagehide 시점에 대기 중 저장을 즉시 실행한다. 새로고침 시 마지막 확정 조작값이 복원되어야 한다.
- 숫자·막대 애니메이션은 150~250ms로 설정한다. 연속 조작 시 이전 애니메이션을 취소하고 마지막 상태를 반영한다.
- 전체 초기화 버튼 → “모든 설정을 기본값으로 되돌릴까요?” 확인 → 앱 전용 저장 키만 제거 → 기본값 재렌더링. 취소하면 변경하지 않는다. localStorage.clear()는 사용하지 않는다.

## 9. localStorage 명세

저장 키는 `small-spend-simulator:v1` 하나를 사용한다. 파생 결과는 저장하지 않고 매번 다시 계산한다.

```json
{
  "schemaVersion": 1,
  "activeCategory": "coffee",
  "coffee": { "unitPrice": 5000, "weeklyCount": 5, "reduceCount": 2 },
  "delivery": { "unitPrice": 25000, "monthlyCount": 8, "reduceCount": 2 },
  "subscription": { "monthlyPrice": 15000, "skipMonths": 3 },
  "conversionPrices": { "chicken": 25000, "coffee": 5000, "travel": 500000 }
}
```

### 복원·예외 정책

- 읽기·JSON 파싱·쓰기·삭제는 각각 try/catch로 처리한다.
- 키가 없으면 기본값을 사용한다. 필드 누락, 잘못된 자료형, 유한하지 않은 숫자는 해당 필드만 기본값으로 복구한다.
- 유효한 숫자는 범위 내로 제한하고 가장 가까운 허용 간격으로 보정한다. 현재 횟수를 먼저 보정한 뒤 줄일 횟수를 제한한다.
- 카테고리 값은 허용된 3개 문자열, 환산 가격은 프리셋 중 하나만 허용한다. 그 외 값은 해당 기본값을 적용한다.
- 파싱 불가 또는 지원하지 않는 schemaVersion이면 전체 기본값으로 시작하고 설정을 복구했다는 안내를 한 번 표시한다. 다음 변경 때 정상 형식으로 저장한다.
- 저장이 차단되거나 용량 문제가 발생하면 메모리 상태로 계산을 계속하고 “이 환경에서는 설정을 저장할 수 없어요. 새로고침하면 초기화될 수 있어요”를 표시한다. 저장 성공으로 표시하지 않는다.
- 정상 저장 시 “이 브라우저에 자동 저장돼요”를 표시한다. 브라우저 데이터 삭제·시크릿 모드 종료·기기 또는 도메인 변경 시 유지되지 않을 수 있음을 설정 하단에 안내한다.
- 초기화 시 삭제가 실패하면 기본값 덮어쓰기를 시도한다. 둘 다 실패하면 화면만 초기화됐으며 이전 설정이 다시 나타날 수 있음을 알린다.
- 여러 탭 간 실시간 동기화는 MVP에서 제외한다. 마지막으로 성공한 저장값을 다음 로드에 사용한다.

## 10. 디자인 및 접근성

- 스타일: 밝은 크림 배경, 둥근 카드, 이모지 아이콘, 가벼운 그림자.
- 색상 예시: 배경 #FFF9F2, 본문 #27243A, 커피 #F6B66B, 배달 #90D7B5, 구독 #B7A4EC. 밝은 카드 위 글자는 어두운 색으로 유지한다.
- 핵심 절약액은 32~48px, 본문은 16px 이상을 권장한다. 모바일에서는 금액 줄바꿈과 잘림을 방지한다.
- 카드 모서리는 20px, 주요 조작 영역은 최소 44×44px, 화면 좌우 여백은 모바일 16px 이상으로 한다.
- 360px 화면에서 가로 스크롤 없이 사용할 수 있어야 한다. 768px 미만 한 열, 이상에서는 입력/결과 두 열로 전환한다.
- 슬라이더는 기본 input[type="range"]를 사용하고 label, 현재 값, 단위를 연결한다. 키보드 방향키로 조절 가능해야 한다.
- 탭은 선택 상태와 키보드 이동을 지원한다. 포커스 테두리를 숨기지 않는다.
- 그래프는 색상뿐 아니라 항목명·금액·비율을 함께 표시한다. 일반 텍스트 명도 대비는 4.5:1 이상으로 검증한다.
- 결과 변경 안내는 aria-live="polite"를 사용하되 조작이 멈춘 뒤 한 번 알리도록 제한한다.
- prefers-reduced-motion이 설정되면 숫자·그래프 애니메이션을 제거한다.

## 11. 기술 구현 및 배포

- HTML5 + CSS3 + 순수 JavaScript만 사용한다. React/Vue, 패키지 설치, 빌드 도구, 외부 라이브러리는 사용하지 않는다.
- 최종 앱 산출물은 CSS와 JavaScript를 포함한 `index.html` 1개다. 시스템 글꼴·이모지·CSS 그래프를 사용하며 외부 리소스를 호출하지 않는다.
- 내부 코드는 기본 설정/상태, 검증, 순수 계산 함수, 화면 렌더링, 저장 처리, 이벤트 연결로 구분한다.
- 권장 함수: normalizeState(), calculateAnnual(), calculateConversions(), render(), loadState(), saveState(), resetState(). 계산 함수는 DOM·localStorage에 접근하지 않는다.
- UI는 textContent와 안전한 DOM API로 갱신한다. 저장된 문자열을 innerHTML에 삽입하지 않는다.
- HTTPS 정적 호스팅에 index.html을 배포한다. 서버 프로그램·DB·API 키는 필요 없다. 저장은 동일 origin의 브라우저에 한정된다.
- 로컬 파일 직접 열기는 미리보기 용도로만 사용한다. 저장 지속성의 완료 검증은 배포 URL 또는 localhost에서 수행한다.
- Chrome·Edge·Safari의 검증 시점 안정 버전과 Android Chrome/iOS Safari에서 핵심 흐름을 확인한다.
- 로그인·추적 스크립트·외부 분석 도구를 넣지 않는다. 이용자 설정을 서버로 전송하지 않는다.

## 12. 인수 기준
